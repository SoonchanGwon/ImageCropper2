# 이미지 일괄 자르기 (ImageCropper)

폴더 안의 모든 이미지를 **같은 영역으로 한 번에 잘라** 지정한 폴더에 저장하는 Windows 11용 프로그램입니다.
가로 길이가 같은 스크린샷 여러 장에서 같은 부분만 잘라낼 때 편리합니다.

## 주요 기능

- **원본 폴더 불러오기**: 찾아보기 또는 폴더를 창에 끌어다 놓기
- **크기 목록**: 이미지별 가로·세로 크기를 표시하고, 가로 크기가 다른 이미지가 있으면 노란색으로 알려 줌
- **자르기 영역**
  - 가로 크기는 기본값이 가장 긴 가로 크기이며, 숫자로 수정 가능
  - 세로는 시작 위치와 크기를 숫자로 입력하거나, 미리보기에서 테두리를 끌어서 조절
  - 영역 안쪽을 끌면 이동, 바깥을 끌면 새 영역 그리기
- **저장 옵션**: 원본 형식 유지 / PNG / JPG(품질 95), 파일명 접미사(예: `_crop`)
- **안전장치**: 원본 덮어쓰기나 같은 이름의 파일이 있을 때 실행 전에 확인
- 마지막으로 사용한 원본·저장 폴더 기억

지원 형식: PNG, JPG/JPEG, BMP, WEBP, TIF/TIFF, GIF(첫 프레임)

## 사용 방법

1. **원본 폴더**를 선택합니다.
2. **자르기 영역**에서 가로·세로 시작 위치와 크기를 정합니다.
3. **저장 폴더**를 선택합니다.
4. **실행**을 누르면 모든 이미지가 잘려서 저장 폴더에 저장됩니다.

## 실행 / 빌드

Python 3.10 이상이 필요합니다.

```powershell
pip install -r requirements.txt
python image_cropper.py
```

단일 실행 파일(`dist\ImageCropper.exe`)로 빌드하기:

```powershell
.\build.bat
```

서명하지 않은 exe라서 처음 실행할 때 Windows SmartScreen 경고가 뜰 수 있습니다. "추가 정보 → 실행"을 누르면 됩니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `image_cropper.py` | 프로그램 본체 (PySide6 GUI + Pillow) |
| `icon.ico` | 앱 아이콘 |
| `make_icon.py` | 아이콘 생성 스크립트 |
| `build.bat` | exe 빌드 스크립트 |
| `requirements.txt` | 필요한 패키지 |
